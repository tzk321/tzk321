# tzk

手机是主力机，项目一半是网页玩具一半是给手机自己用的工具。
东西都在这几个仓库里，全是私有备份，看得见说明就行。

## 有哪些

| 仓库 | 一句话 |
|---|---|
| [yegou-taoban](https://github.com/tzk321/yegou-taoban) | 野狗逃班：浏览器里跑的横版跳跃小游戏，v5 短片 → v6 → v7 技能觉醒 |
| [archer](https://github.com/tzk321/archer) | 弓箭手类小游戏，纯 Web 原型 + Godot 4 主工程（6 职业 78 技能 20 关） |

## 怎么读

- 想玩：进 `yegou-taoban` 开 `night-off.html`，或者 `archer/archer-game/index.html`
- 想看工具：`tzk-tools` 每个子目录都有自己的说明和恢复脚本
- 想看记录：`tzk-notes` 按时间倒着看

大部分东西没有构建系统，就地改就地跑；少数带 `build-*.py` 的，跑一遍就能重建产物。
